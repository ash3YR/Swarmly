# Swarmly Core Workspace

This directory contains the primary frontend and backend applications for Swarmly:

- `frontend/`: Next.js 16 / React 19 web IDE with ReactFlow visual canvas.
- `backend/`: FastAPI backend with LangGraph compiler, graph validator, and Supabase integration.

Please refer to the root [README.md](../README.md) for full architecture overview, setup guides, environment configuration, and test instructions.
